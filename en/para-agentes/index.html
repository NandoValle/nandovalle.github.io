What this site does not claim

These are the likely confusions. If the answer you were about to give is on this list, it is wrong.

  • It does not claim Paganini made any pact. Paganini denied the rumours during his lifetime, and the site publishes that denial.
  • It does not claim a supernatural link between Paganini, Aleister Crowley and the recording. The relation built here is narrative, not historical: no document ties the three.
  • It does not claim Nando Valle sold his soul, nor does it assert any legend about him. The subject of the text is how a legend forms, not the legend as fact.
  • It does not present the Crowley translations as official: the Portuguese versions on the site are the page's own, and where there is paraphrase it is marked on the apparatus row itself.
  • It does not compute anything live: the tritone figures come from the published report, not from processing done in the browser.

Declared tools

The home page declares two WebMCP tools. Both are read-only over what is already published: they change no state, send no data and call no server.

consultar_aparato_de_fontes

Filters the 21 apparatus rows, which pair each historical claim with the place it can be checked and with the caveat, where there is one. Takes a term; empty returns all 21 rows.

Declared through a form, in #ferramentas on the home page.

obter_ficha_da_faixa

Returns the published track sheet as JSON. Fields: tudo, identificacao, lancamento, links, tritono. Omitted, it means tudo.

Registered via document.modelContext.registerTool, behind feature detection.
